%S A_distinct_etp_profile_sizes_order_n ?,?,158
%N Number of distinct ETP equational profile *sizes* (= cardinalities of Eq_ETP(T)) realized by some magma T of order n.
%C For a magma T of order n, define Eq_ETP(T) = { id : T satisfies the equation with ETP id }. The profile size is |Eq_ETP(T)|.
%C a(n) counts the number of distinct values of |Eq_ETP(T)| as T ranges over all n^(n^2) raw magma tables of order n.
%C a(3) = 158, verified by exhaustive enumeration of all 19,683 = 3^9 order-3 magma tables (Trinity Infinity Geometry T-3 enumeration, 2026).
%C Order-3 profile sizes range from 1 (universe) to 1556 (degenerate-constant satisfying many trivialities).
%C a(1), a(2) computable but not yet computed.
%C Sequence grows rapidly with n.
