Family C — the closure of commutativity

Definition. Family C is the implication-closure of ETP equation 43 (x ⋄ y = y ⋄ x, commutativity) under the ETP depth-3 equation enumeration. The closure has exactly 14 members. Verified against ETP's 8.18M-edge proved-implication graph (verify_family_c.py).

Command-line query

python scripts/query.py stats                 # summary
python scripts/query.py family C              # Family C contents
python scripts/query.py equation 43           # closure containing equation 43
python scripts/query.py profile 14            # everything at profile size 14
python scripts/query.py magma "[[0,1,2],[1,2,0],[2,0,1]]"  # profile of a table

JSON output via --json. Magma profile lookup requires ETP's explore_magma.py (set ETP_PATH).
