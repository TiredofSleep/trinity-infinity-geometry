## J15 — *Joint Closure, Per-Coordinate Fuse Data, and a Closed-Form Algebraic Attractor of Two Commutative Binary Operations on Z/10Z*

### 1. §6 Theorem 6.2 proof upgrade (sketch → explicit Lefschetz/index argument)

The target was Theorem 5.6 (`thm:attractor`, "Interior existence"), whose original proof contained the sketch "standard topological arguments (e.g., Lefschetz fixed-point theory or the index calculation for a repellor on the boundary of a contractible set)".

The replacement proof:

```
By Brouwer's fixed-point theorem on the closed simplex
Δ³_C (a compact convex set, on which F_α is continuous),
at least one fixed point exists. By Lemma 5.5, the only
boundary fixed point in Δ³_C for α ∈ (0,1) is the vertex
e_0, and e_0 is a repellor: the spectral computation gives
DF_α(e_0) = diag(2, 2(1-α), 2(1-α)), so all three eigenvalues
have magnitude > 1 for α ∈ (0,1), i.e., e_0 is a hyperbolic
source.

We invoke Lefschetz fixed-point theorem (Dold, Brown). The
simplex Δ³_C is contractible, so χ(Δ³_C) = 1, and F_α is
homotopic to id via the straight-line homotopy, giving
L(F_α) = χ(Δ³_C) = 1.

The local index of the hyperbolic source e_0 is sign(det(I -
DF_α(e_0))) = sign(-1 · (2α-1)²) = -1 for α ∈ (0,1)\{1/2}.
(More generally, a hyperbolic source in dimension n has local
index (-1)^n; here n = 3 so (-1)³ = -1.)

For α ∈ (0,1)\{1/2}, the sum formula gives
   Σ_{p∈Fix∩interior} ind_{F_α}(p) = L(F_α) - ind_{F_α}(e_0)
                                    = 1 - (-1) = 2 ≠ 0,
forcing at least one interior fixed point. At α = 1/2 the
linearization at e_0 is degenerate (det(I-DF) = 0); for this
value we invoke the explicit closed-form construction of
Theorems 7.1 and 8.1.
```

(Note: the task template suggested `(-1)^(n-1)` for the boundary-repellor index but for our specific case the correct local index of a hyperbolic source is `(-1)^n`. With n = 3, this gives -1, and 1 - (-1) = 2 ≠ 0, which correctly forces an interior fixed point. The task-template formula `1 - (-1)^(n-1) = 1 - (-1)² = 0` would have been degenerate at n=3 and not forced anything; the corrected computation above is what the manuscript now contains.)

Two new bibliography references added: **Dold 1972** (*Lectures on Algebraic Topology*, GTM/Grundlehren 200, Springer) and **Brown 1971** (*The Lefschetz Fixed Point Theorem*, Scott Foresman).
