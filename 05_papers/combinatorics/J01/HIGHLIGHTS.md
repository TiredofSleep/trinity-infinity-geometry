# Highlights — J01 submission to JCT-A

Elsevier requires 3–5 highlights, each a single sentence of at most 85 characters
(including spaces). Highlights appear at the top of the article and in
ScienceDirect search results.

Paste these into the "Highlights" field of the Elsevier Editorial Manager
submission form (one bullet per line, no leading dash):

```
Explicit O(1/N) bound on non-associativity density for binary CL on Z/NZ
For squarefree N >= 3: sigma(N) < 2/N, with N*sigma(N) -> 2 from below
Closed form for residual count E_h(N) via roots of b^2 + b - 1 mod N
Proof elementary: CRT, quadratic reciprocity, three-case enumeration
Verified at machine precision over every squarefree N <= 200 (no exceptions)
```

Character counts (must be <= 85 each):
1. "Explicit O(1/N) bound on non-associativity density for binary CL on Z/NZ"  -> 73 chars
2. "For squarefree N >= 3: sigma(N) < 2/N, with N*sigma(N) -> 2 from below"     -> 70 chars
3. "Closed form for residual count E_h(N) via roots of b^2 + b - 1 mod N"       -> 68 chars
4. "Proof elementary: CRT, quadratic reciprocity, three-case enumeration"       -> 69 chars
5. "Verified at machine precision over every squarefree N <= 200 (no exceptions)" -> 76 chars

All five are under the 85-character cap.

---

Note: Elsevier Editorial Manager accepts these as plain text. No LaTeX
formatting (the sigma, phi, etc. need ASCII substitutions as shown). The
typeset article will render them with the manuscript's LaTeX symbols, but
the EM submission field is plain ASCII.
