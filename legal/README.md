# Legal — Modular Layers

The framework's legal instrument is split into modular layers for clarity, attorney review, and enforceability. The operative LICENSE at the repository root is intentionally lean; the surrounding charter, acceptable-use, AI-use, trademark, trust, attribution, and contribution documents in this folder are bound to it by reference.

This structure follows separation-of-concerns: copyright + contract terms live in LICENSE; moral / sovereignty declarations live in CHARTER; specific prohibited uses live in ACCEPTABLE_USE; etc. Each can be reasoned about, reviewed, and (where appropriate) revised independently.
